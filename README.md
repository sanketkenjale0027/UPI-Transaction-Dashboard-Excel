# 💳 UPI Transactions Dashboard – Excel

## 📊 Project Overview

This project showcases an interactive UPI Transactions Analysis Dashboard developed using Microsoft Excel. It analyzes approximately 5,02,888 transaction records for the month of May, providing insights into UPI payment trends, transaction performance, payment applications, bank-wise analysis, and state-wise distribution.

The dashboard transforms large-scale transaction data into meaningful insights through interactive visualizations and filters.

## 📈 Key Dashboard Features

- Total Transactions: Analysis of 5,02,888 UPI transactions.
- Total Transaction Amount: Overall transaction value in INR.
- Total Cashback: Cashback distribution analysis.
- Success Rate: Monitoring successful UPI transactions.
- Suspected Fraud: Analysis of suspected fraudulent transactions.
- Daily Transaction Trends: Visualization of daily transaction amounts.
- UPI App Analysis: Comparison of PhonePe, Google Pay, Paytm, Amazon Pay, BHIM, Cred Pay, and WhatsApp Pay.
- Bank-wise Analysis: Comparison of transaction amounts across different banks.
- State-wise Analysis: Geographical distribution of UPI transactions.
- Interactive Filters: Gender, City, Merchant Category, and Merchant Name.

## 📂 Dataset Information

- Dataset: UPI Transaction Data
- Time Period: May
- Total Records: 5,02,888
- Data Type: UPI Payment Transactions

## 🎯 Project Objective

The main objective of this project is to analyze large volumes of UPI transaction data and convert raw data into actionable insights. It helps understand customer payment behavior, transaction trends, popular UPI applications, bank performance, and geographical transaction patterns.

## 💡 Key Learnings

- Handling large datasets in Excel.
- Creating interactive dashboards using Pivot Tables and Charts.
- Applying slicers for dynamic data filtering.
- Analyzing financial and transaction-related data.
- Presenting complex data through meaningful visualizations.
